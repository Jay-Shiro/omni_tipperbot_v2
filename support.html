Are tips on-chain?

No. Tips are internal ledger transfers (off-chain). Deposits and withdrawals are on-chain.

What are the fees?

Tips are free. Deposits and withdrawals include a 0.1% service fee.

Which tokens are supported?

Unlimited Base ERC‑20 tokens can be added by contract address (operator-controlled).

I withdrew but don’t see funds yet.

Withdrawals are on-chain; check the transaction on a Base explorer. Network congestion can delay confirmation.

How do I self-host?

Use the Docker Compose quickstart and enable monitoring to keep things healthy.

How do I add a token?

Operators can add ERC‑20s via the admin command using a contract address.
